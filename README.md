# PRL Royale · Misión Supervivencia

Juego educativo de Prevención de Riesgos Laborales (IPE I): factores químicos, biológicos y riesgos psicosociales.

- 75 preguntas en el banco, 25 por partida (opción múltiple, verdadero/falso y ordenar secuencias)
- 5 vidas, puntuación por acierto, rapidez y vidas restantes, y valoración de 1 a 5 estrellas

Se juega abriendo `index.html` o desde GitHub Pages.
